# Audit repairs and validation — 2026-10-22

This change addresses the [0.1.2 audit](2026-10-22-code-audit.md). All standard
VNA measurement/display types, menus, SD features, ANT pages and both ANT
calibration slots remain available. These repairs are included in version 0.1.3;
the on-disk layout is unchanged.

Additional audit follow-ups were addressed:

- Saved/imported properties validate point counts, frequencies, trace/marker
  selectors, reference resistances, trace values and finite calibration samples.
  Configuration/RTC restore bounds-check bandwidth, brightness and lever selection.
- H4 I2C waits are bounded even if the system tick is stopped. NACK, bus/arbitration
  errors and stuck flags return failure; receive-only transfers no longer wait
  for a preceding transmit completion. Register-level fault/retry tests cover this.
- Each DMA handler clears only its channel's flags; IRQ tests verify this while
  retaining nested-wakeup checks.
- Scheduler slots remain reserved during creation and until the task is joined;
  tests cover concurrent creation and immediate thread exit.
- Contribution instructions describe H4/`antenna_expert`; CI fails if DFU suffix
  validation fails.

## Compatibility details

SD Touchstone import supports uniform Hz / S / real-imaginary / 50-ohm files,
including the firmware's own exports. Unsupported units/data encodings or
nonuniform grids now report an error instead of being silently misinterpreted.
Headerless legacy Hz/RI input remains accepted. These checks do not restrict USB
measurement export or normal VNA sweeps.

SD CAL imports use the ANT walkthrough's temporary scratch area only while no
walkthrough is active. They do not overwrite saved slots or bypass the dedicated
ANT slot writer. Saved images need a valid checksum and fields; this intentionally
rejects corrupt files, including old exports whose checksum was already stale.
The existing private ANT1 grid interpretation and 0.1.2 V/U recalibration policy
are unchanged; no fresh recalibration is required solely by these repairs.

## Flash and RAM

Applied size optimization to the entire LCD and Si5351 drivers. The original
isolated experiment saved 484 bytes together; no features were removed. Also
replaced ANT's double-precision MHz divisions with rounded integer Hz formatting,
which preserves exact displayed frequencies, and removed the unused event queue.
Validation and recovery code consumes some of those savings.

The final WSL H4 build uses 116,592 bytes of the 116,736-byte (114 KiB) firmware
region, leaving **144 bytes free**. This is a net increase of 88 bytes over the
previously flashed 0.1.2 image after applying both fixes and savings. Text is
116,028 bytes, initialized data 564 bytes and BSS 48,376 bytes. The main-RAM heap
boundary leaves 608 bytes; this is not a measurement of runtime stack headroom.
CCM uses 8,176 of 8,192 bytes. Removing the unused event queue saves 240 bytes RAM.
All calibration/configuration addresses remain unchanged. Flash and CCM remain
tight; future features still need measured budgets.

## Device flash and USB checks

Flashed H4 serial `205431682033` with version 0.1.3 after saving a full 256 KiB
backup. Programmer verification passed, and an independent full-flash readback
matched the firmware byte-for-byte. All 145,408 bytes at and above `0x0801C800`
were unchanged, preserving saved settings and calibration. Backup, readback,
programming logs and verification JSON are in `v0.1.3\flash-01`.

The device started and returned on COM13. USB `info` reports AntExpert 0.1.3,
`version` reports protocol 0.9.102, and two S11 snapshots each returned 101 finite
complex samples. These checks confirm USB communication and readable measurement
data; they do not establish RF accuracy or confirm physical controls.

## Hardware follow-up

Host tests and compilation do not establish RF accuracy or peripheral timing on
the instrument. Before publishing/flashing as a release, check battery-only boot,
USB unplug/reconnect, touch/roller, CW, known Smith loads, ordinary CAL plus ANT
HF/V/U save/recall, Multi/Cable pages, and NanoVNA-Saver. Exercise SD error handling
if using an SD card. The user confirmed normal ANT and VNA sweeps, responsive touch and roller,
and normal operation after unplugging USB and restarting on battery, with no
blanking, freezes or resets after the 0.1.3 flash.
